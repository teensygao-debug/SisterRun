# 姐妹快跑手机发布优化设计

## 目标

在不改变跑酷、Fearless、键盘、触屏和 Xbox 手柄规则的前提下，降低手机进入页面时的资源开销，修复竖屏拉伸，确保发布目录只包含当前版本实际引用的资源，并把背景音乐下载延后到玩家主动开始游戏之后。

## 设计

- 首屏只加载白天背景、主角跑步动画和勇气能量包等开始画面/开局必需素材；其他角色状态、敌人、夜景、HUD 和特效在开始游戏后分批加载。未加载完成时沿用现有程序化绘制，不阻塞游玩。
- 删除未被游戏消费的对话气泡清单项，使其不进入发布包；源素材库保留，避免破坏美术原始资料。
- 手机竖屏保持 16:9，不再拉伸画布，并用全屏提示要求玩家旋转为横屏；横屏和桌面布局保持现状。
- 移除 HTML 的 BGM preload。页面初始化时不创建 Audio，也不设置音频地址；玩家按开始后才创建并播放。
- 构建脚本每次先清空 `dist` 和 `sisterrun-sandbox-iframe`，再仅复制当前 HTML 实际引用的资源。

## 验收

- 首屏不请求 BGM，首屏图片请求限制为核心资源，之后开始游戏才加载延迟资源。
- 390×844 竖屏时游戏画布仍为 16:9，旋转提示可见；844×390 横屏时提示隐藏。
- 构建前人为加入的旧文件会被删除，发布目录不再包含对话气泡和旧版重复文件。
- 全部自动化测试通过，并在手机横屏复测帧率、触控和 Fearless 流程。
