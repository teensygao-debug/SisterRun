# 姐妹快跑 × WeUs：Xbox 手柄与电视投屏适配设计

## 目标

在不改变现有键盘和触控操作的前提下，通过浏览器 Gamepad API 接入连接到 Mac 的 Xbox 手柄。游戏仍由 Mac 上的本地 HTTP 服务器运行，再将 Mac 画面投到电视。

「勇气能量包」的随机掉落间隔后续进一步调整为 8–15 秒，以增加每局出现次数。

## 运行方式

- 游戏地址保持为 `http://127.0.0.1:8000/`。
- Xbox 手柄连接 Mac，由打开游戏页面的浏览器直接读取手柄输入。
- 电视只负责显示 Mac 画面，不要求电视浏览器直接识别手柄。
- 浏览器通常需要玩家先按一次手柄按键，才会向网页暴露手柄状态。

## 按键映射（方案 1）

| Xbox 输入 | 游戏行为 | 未开局时的行为 |
| --- | --- | --- |
| A | 跳跃 | 开始游戏并立即跳跃 |
| 十字键 ↑ | 跳跃 | 开始游戏并立即跳跃 |
| 左摇杆向上 | 跳跃 | 开始游戏并立即跳跃 |
| X 按下 | 开始蓄力 | 只开始游戏，不消耗弹药 |
| X 松开 | 快按投掷；长按后冲刺 | 若由 X 开局，本次松开不攻击 |
| Menu | 开始／重新开始 | 开始或重新开始，不触发跳跃和攻击 |

X 键复用现有攻击逻辑：快速按下并松开投掷一片普通卫生巾；按住达到现有蓄力阈值后松开触发冲刺。勇气能量包只负责触发或延长 Fearless，不会成为投掷物。

## 输入处理规则

1. 每帧在游戏更新前读取一次 `navigator.getGamepads()`。
2. 只使用第一个产生有效输入的标准映射手柄；不加入双人或多手柄功能。
3. A、十字键 ↑、Menu 和 X 按下只在“从未按到按下”的瞬间触发，避免按住时每帧重复操作。
4. 左摇杆向上在 Y 轴小于或等于 `-0.65` 时触发一次跳跃；回到 `-0.35` 以上后才允许再次触发，避免摇杆抖动造成连续跳跃。
5. 同一帧多个跳跃输入只触发一次跳跃。
6. 手柄断开、窗口失焦或一局结束时，清除手柄按键状态并取消未完成的蓄力，不自动释放攻击。
7. 浏览器不支持 Gamepad API 时，键盘和触控操作继续正常工作。

## 电视端提示

开始界面增加一行大号、易读的操作提示：

`手柄 A：跳跃 · X：投掷/蓄力 · Menu：开始`

开始界面同时显示简短连接状态：

- 未检测时：`手柄未检测 · 请按任意手柄键`
- 检测后：`Xbox 手柄已连接`
- 浏览器不支持时：`当前浏览器不支持手柄 · 可使用键盘或触控`

连接状态只用于反馈，不遮挡游戏 HUD，也不改变键盘和触控入口。

## 勇气能量包节奏

- 每次成功生成后，下一次随机等待区间改为 8–15 个“有效跑酷秒”。
- 等待只在角色实际跑动时推进；暂停、开局前和结束后不计时。
- 保留现有 12 秒开局保护和距离安全检查。虽然随机最短间隔为 8 秒，第一包仍不会早于第 12 秒掉落。
- 拾取效果保持不变：立即触发 5 秒 Fearless；若已处于 Fearless，则增加 5 秒，继续遵守现有 15 秒上限。

## 修改范围

- 在根目录 `index.html` 内增加手柄状态采样、边沿检测、映射和界面提示。
- 更新勇气能量包导演的间隔常量及对应测试。
- 通过现有构建脚本同步生成 `dist/index.html` 和 `sisterrun-sandbox-iframe/index.html`。
- 不改变角色物理、障碍物、弹药初始值、Fearless 规则、键盘和触控映射。

## 验证方式

自动测试需要覆盖：

- A、十字键 ↑ 和左摇杆向上只触发一次跳跃。
- X 快按触发一次投掷，X 长按走现有蓄力／冲刺流程。
- X 开局不会误消耗初始 10 个弹药。
- Menu 可以开始和重新开始。
- 手柄断开或失焦时取消蓄力。
- 第一包保留 12 秒开局保护；后续随机间隔都落在 8–15 秒内。
- 原有键盘、触控、HUD、碰撞、结算和静态构建测试继续通过。

本机硬件验收：刷新本地服务器页面，先按一次 Xbox 手柄按键，确认页面显示“Xbox 手柄已连接”，再实际完成开始、跳跃、投掷、蓄力冲刺和重新开始。

## 成功标准

1. `http://127.0.0.1:8000/` 可直接打开最新构建页面。
2. Xbox 手柄按方案 1 操作，且长按不会造成重复跳跃或重复开始。
3. 键盘和触控无回归。
4. 勇气能量包后续随机间隔为 8–15 秒，第一包不早于第 12 秒。
5. 实现前创建可恢复快照，并记录路径与校验值。
