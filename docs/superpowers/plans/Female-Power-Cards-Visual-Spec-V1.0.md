# SisterRun × WeUs「女性力量卡牌」视觉规范 V1.0

> Status: **FROZEN / 已冻结**\
> 用途：供 Codex 实现 SisterRun 游戏结束后的抽卡页面、卡牌翻转展示与后续
> 8 张正面卡牌资产接入。\
> 原则：**不得擅自扩展、重构或重新设计已冻结的视觉系统。**

------------------------------------------------------------------------

## 1. 视觉系统总览

女性力量卡牌是一套 **WeUs × SisterRun** 联名数字收藏卡。

核心视觉关键词：

-   暗黑
-   黑金
-   未来科技
-   女性力量
-   知识与技术
-   克制
-   大面积留白
-   精密金属线条
-   8-bit 像素游戏世界
-   WeUs 品牌玫红

整套卡牌包含两套互补的视觉语言：

### FRONT / 正面

**极简黑金未来知识档案**

表达女性掌握知识、AI、工程、技术与创造工具。视觉克制、安静、有力量。

### BACK / 背面

**WeUs × SisterRun 8-bit 游戏世界**

使用 WeUs 女巫帽、品牌识别与 SisterRun
像素游戏语言，形成更鲜明、更游戏化的卡背。

------------------------------------------------------------------------

# 2. FRONT / 正面视觉规范

## 2.1 核心概念

正面不是传统塔罗牌，也不是复杂 Cyberpunk 海报。

它是一张来自未来的：

**Female Power Archive / 女性力量档案卡**

女性必须是技术、知识和工具的**主体、操作者和创造者**，不能只是被科技元素包围的装饰人物。

------------------------------------------------------------------------

## 2.2 固定视觉结构

8 张卡牌必须共享同一套基础结构：

1.  竖版圆角卡牌。
2.  黑色 / 极深墨绿色哑光基底。
3.  极细金属金色外边框。
4.  大面积深色留白。
5.  顶部固定标题区域。
6.  中央一个主要女性视觉。
7.  少量科技/知识符号辅助中央视觉。
8.  下方固定文字信息区。
9.  底部固定符号区与 `WeUs` 文字标识。

8 张卡之间**不改变基础版式、边框语言、字体层级与信息区位置**。

------------------------------------------------------------------------

## 2.3 正面允许变化的内容

每张卡只允许重点改变：

1.  **女性人物 / 动作**
2.  **她掌握的知识、技术或力量的核心视觉隐喻**
3.  **卡牌标题、正文及署名内容**

其他视觉结构保持一致。

------------------------------------------------------------------------

## 2.4 科技元素使用规则

可以使用：

-   AI
-   数据节点
-   极简代码
-   工程图
-   电路 / 线路
-   数据结构
-   神经网络
-   科学图示
-   几何结构
-   轨道结构
-   知识网络
-   极简 HUD
-   未来工具或界面

但这些元素只能作为**辅助信息**。

### 必须避免

-   不得把科技图案铺满整个画面。
-   不增加左右两侧密集科技面板。
-   不做复杂 Cyberpunk HUD。
-   不堆叠大量代码窗口。
-   不堆叠星象、炼金、神秘学符号。
-   不做传统塔罗牌式繁复装饰。
-   不使用大量霓虹颜色。
-   不为了"科技感"牺牲留白。

视觉判断标准：

> 删除一个元素后，如果核心叙事仍成立，就优先删除。

------------------------------------------------------------------------

## 2.5 色彩

主背景：

-   Black
-   Charcoal
-   Extremely Dark Forest Green

主线条：

-   Antique Gold
-   Muted Metallic Gold

正面整体应保持黑金双色为主。

玫红、紫、青蓝等颜色如需出现，只能作为极少量能量信号，不得成为主色。

------------------------------------------------------------------------

## 2.6 人物表现

女性人物应表现为：

-   正在操作
-   正在创造
-   正在理解
-   正在研究
-   正在构建
-   正在连接
-   正在使用工具改变环境

避免：

-   被动站立
-   纯肖像
-   性感化
-   魔法少女
-   女神化
-   "女性只是科技背景中的漂亮人物"

核心表达：

**Women understand technology.\
Women use technology.\
Women build the future.**

------------------------------------------------------------------------

## 2.7 正面 Master Prompt


# 3. BACK / 背面视觉规范

## 3.1 状态

**背面视觉已经冻结。**

后续开发与 8 张卡牌设计过程中：

> 不再添加任何内容，不重新设计，不改变内容结构。

所有卡牌共用**同一张背面资产**。

------------------------------------------------------------------------

## 3.2 背面核心语言

背面承担的是：

**WeUs 品牌世界 × SisterRun 8-bit 游戏世界**

与正面的安静黑金形成反差。

主要元素包括：

-   深黑背景
-   金色科技边框
-   WeUs 品牌识别
-   WeUs 女巫帽
-   WeUs 玫红
-   SisterRun 8-bit 像素语言
-   像素城市
-   奔跑女性角色
-   游戏 HUD / 图标
-   `月经 / 关爱 / 连结 / 创造`
-   底部 `WeUs` 文字

------------------------------------------------------------------------

## 3.3 WeUs 品牌资产规则

WeUs Logo、女巫帽等正式品牌素材应优先使用品牌提供的原始资产。

### 禁止

-   AI 重新设计 Logo
-   AI 重绘 Logo
-   改变女巫帽轮廓
-   改变品牌资产比例
-   用"相似 Logo"替代正式 Logo
-   擅自增加新的品牌符号

若正式页面使用的是已导出的卡背 PNG，则 Codex **不得在网页中再次用
HTML/CSS 重构卡背内部视觉**。

------------------------------------------------------------------------

# 4. FRONT × BACK 关系

正反面不是同一种画风的简单复制，而是有意识的反差：

  正面 FRONT     背面 BACK
  -------------- -----------------------------
  安静           动态
  极简           游戏化
  黑金           黑金 + WeUs 玫红 + 像素霓虹
  知识档案       SisterRun 游戏世界
  女性掌握技术   女性向前奔跑
  大量留白       信息相对丰富
  线条型         8-bit 像素型

共同点：

-   深黑基底
-   金属金色边框
-   女性力量
-   未来感
-   WeUs 品牌
-   圆角收藏卡比例

------------------------------------------------------------------------

# 5. 游戏页面资产规范

Codex 应将正面和背面作为**独立 PNG 图片资产**使用。

建议：

``` text
/assets/cards/
  card-back.png
  card-01-front.png
  card-02-front.png
  card-03-front.png
  card-04-front.png
  card-05-front.png
  card-06-front.png
  card-07-front.png
  card-08-front.png
```

其中：

-   `card-back.png`：8 张卡共用。
-   `card-01-front.png` \~ `card-08-front.png`：8 张不同女性力量卡正面。

------------------------------------------------------------------------

# 6. 图片输出规范

为了保证网页翻牌时正反面对齐：

-   文件格式：PNG
-   正面和背面使用相同画布比例
-   相同圆角外轮廓
-   卡牌在画布中的位置一致
-   建议透明外部背景
-   卡牌内部黑色基底必须保留
-   不带展示 Mockup 阴影
-   不带桌面、纸张、墙面等场景背景
-   不把正反面合并为一张图
-   每张卡必须是独立文件
-   移动端优先保证文字与边缘清晰

------------------------------------------------------------------------

# 7. Codex 实现约束

Codex 在抽卡页面中只负责：

1.  加载卡牌 PNG。
2.  显示统一背面。
3.  用户选择后执行翻牌动画。
4.  翻转后显示对应正面 PNG。
5.  支持保存对应正面图片。
6.  保证移动端适配。

Codex **不负责重新设计卡牌内部视觉**。

不要：

-   用 CSS 重画卡牌边框
-   用 HTML 重排卡牌内部文字
-   把人物、Logo、标题拆成网页元素重新组合
-   给卡牌 PNG 再叠加新的图案
-   添加额外滤镜改变卡牌颜色
-   自动增加 Glow / Shadow / Neon 等视觉效果
-   裁切卡牌内部内容

卡牌 PNG 应作为完整视觉资产显示。

------------------------------------------------------------------------

# 8. Frozen Design Checklist

在新增任何一张卡之前检查：

-   [ ] 是否仍然是黑色 / 极深墨绿基底？
-   [ ] 是否仍然使用极细金属金边框？
-   [ ] 是否保留足够大的留白？
-   [ ] 正面是否只有一个主要女性视觉？
-   [ ] 女性是否是知识或技术的操作者？
-   [ ] 科技元素是否只是辅助？
-   [ ] 是否避免了密集 Cyberpunk HUD？
-   [ ] 是否避免了传统塔罗式装饰堆叠？
-   [ ] 是否保持固定文字层级？
-   [ ] 是否保持底部 WeUs？
-   [ ] 是否没有修改背面？
-   [ ] 是否与其他卡牌保持统一版式？

若以上任一项不满足，应优先修正，而不是新增视觉元素。

------------------------------------------------------------------------

# 9. 当前冻结结论

从 V1.0 开始：

**不再讨论"这套卡牌应该长什么样"。**

后续设计工作转入：

**8 Cards Content Design**

每张新卡的设计问题应集中于：

> 这张卡代表哪一种女性力量？\
> 她正在做什么？\
> 她掌握什么知识、技术或能力？\
> 用哪一个核心视觉隐喻把它表达出来？

视觉系统本身保持冻结。
