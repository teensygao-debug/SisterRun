# 姐妹快跑（SISTER, RUN!）

# ART_REFACTOR_V2.md

Version 2.0

---

# Mission

The gameplay prototype is already complete.

From this point forward, **DO NOT add new gameplay mechanics.**

The primary goal of this phase is to rebuild the game's entire visual presentation while keeping gameplay logic unchanged.

This is an **Art Refactor**, not a Feature Update.

Every visual element should look as if it was created by **one pixel artist**.

---

# Core Visual Philosophy

This is NOT a retro pixel game.

This is NOT a cute pixel game.

This is NOT a nostalgic NES game.

The game should feel like:

> A modern arcade action game with comic-style humor, expressive animation, and strong emotional feedback.

Keywords:

* Modern Pixel Art
* Arcade
* Comic Action
* Fast
* Energetic
* Confident
* Funny
* Stylish
* Guangzhou
* Cyberpunk
* Female Power Fantasy

The player should constantly feel:

"I am unstoppable."

---

# Absolute Rule

Never mix pixel assets from different artists.

Never download random pixel sprites.

Never combine free asset packs.

Every asset must belong to ONE visual language.

If an asset doesn't match the Art Bible,

replace it.

Consistency is more important than detail.

---

# Player Character

The heroine is the soul of the game.

She must immediately become recognizable.

Reference:

Run Lola Run

NOT a copy,

but inspired by the same energetic feeling.

---

Appearance

* Bright red short hair
* Hair constantly flowing while running
* White sleeveless tank top
* Green athletic shorts
* White sneakers
* Athletic female body
* Full human anatomy
* Long legs
* Strong running posture

Forbidden:

* Chibi
* Giant head
* Tiny body
* Stick figure
* Cute mascot style

The player must look like she can really sprint.

---

Animation Style

Animation quality should reference:

Celeste

Each movement must communicate momentum.

Idle

2 Frames

Run

8 Frames

Jump

2 Frames

Fall

2 Frames

Throw

4 Frames

Charge

4 Frames

Dash

4 Frames

Fearless Run

8 Frames

Victory

4 Frames

Hair must always move.

Arms should swing dramatically.

Feet should create dust particles.

---

Fearless Mode

When activated:

Hair glows brighter.

Hair flows more dramatically.

Golden outline.

Speed afterimage.

Comic impact lines.

Camera shake increases slightly.

Running animation becomes faster.

The player should instantly feel:

"I've entered a super state."

---

Enemy Design Philosophy

The enemies represent inappropriate public behaviors.

The player is confronting behaviors,

not random monsters.

All enemies must remain humorous,

never horrifying.

No blood.

No violence realism.

Comic exaggeration only.

---

Enemy 01

Smoke

Representation:

A person smoking in public.

Visual focus:

The smoke cloud,

not the smoker.

The smoke itself becomes the obstacle.

Smoke should have looping animation.

Semi-transparent.

Soft edges.

---

Enemy 02

Harasser

Silhouette:

Leaning forward.

Extending one arm.

Facial expression:

Annoying.

Smug.

Comic.

Never realistic.

When defeated:

Spin.

Fly.

Disappear with BOOM.

---

Enemy 03

Drunk Man

Animation:

Walking left-right.

Unstable.

Bottle swinging.

Eyes unfocused.

When hit:

Large comic explosion.

Body spins.

Flies off screen.

Stars appear around head.

---

Comic FX

Every successful attack should create:

BOOM!

BANG!

POW!

K.O.!

Impact Flash

Dust

Stars

Speed Lines

Screen Shake

Everything should exaggerate success.

The game should reward emotion,

not realism.

退！退！退！

886！

---

Hype System

Every 5 consecutive successful actions:

Display a huge comic popup.

Examples:

👑 姐妹杀疯了！

⚡ 谁都拦不住！

🚀 一路狂飙！

🔥 今天状态超神！

The popup should:

Pop animation.

Scale.

Screen shake.

Comic sound effect.

Bright yellow comic frame.

Never static.

---

Color Palette

Use one shared palette.

16–32 colors.

High saturation.

High contrast.

Bright highlights.

Deep shadows.

Avoid:

Gray.

Low contrast.

Painterly shading.

Photorealistic gradients.

---

Outline

Every sprite:

1 pixel dark outline.

No anti-aliasing.

No blurry edges.

Pixel perfect.

---

Lighting

Global light source:

Top-left.

45 degrees.

Every object follows the same lighting rule.

Far skyline

UI Style

The UI is inspired by arcade cabinets.

Pixel font.

Bold outlines.

Bright colors.

Simple icons.

Comic feedback.

Every interaction should feel tactile.

---

Rendering Rules

Never use placeholder art again.

Never use mismatched sprites.

Never replace assets with generic pixel packs.

Every sprite should feel handcrafted.

Every animation should increase emotional feedback.

---

Development Rule

Gameplay code is frozen.

Rendering can be rebuilt.

Logic remains unchanged.

All future visual upgrades must only replace assets,

never rewrite gameplay systems.

---

Final Goal

The player should not remember:

the score.

The player should remember:

"I laughed."

"I felt powerful."

"I immediately wanted another run."

If players say:

"好爽，再来一局。"

then the Art Refactor is successful.
