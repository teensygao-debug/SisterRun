# QA_CHECKLIST_DEMO.md

# 《姐妹快跑》Demo 提交前人工检查清单

目标：  
确保 Demo 能正常运行、视觉统一、核心爽感成立，且没有明显破坏体验的问题。

---

# 0. 基础运行检查

## 必须通过

- [ ] 本地项目可以正常启动
- [ ] 页面无白屏
- [ ] 控制台无红色报错
- [ ] 刷新页面后游戏仍可运行
- [ ] Start / Restart 按钮可点击
- [ ] 游戏结束后可以重新开始
- [ ] 第一次加载时间可接受
- [ ] 图片资源没有 404
- [ ] 音频资源没有 404

## 快速判定

如果这部分有问题，先不要检查美术。  
先修运行稳定性。

---

# 1. 主角动画检查

## Run

- [ ] 主角已替换成正式红发女主
- [ ] 不是 Q 版
- [ ] 不是极简“头 + 身体”
- [ ] 身体比例完整
- [ ] 红色短发明显
- [ ] 白色无袖背心明显
- [ ] 绿色短裤明显
- [ ] 白色运动鞋明显
- [ ] 跑步动画能循环
- [ ] 跑步时头发有动感
- [ ] 跑步时身体没有明显抖动
- [ ] 脚底没有严重上下漂移
- [ ] 角色没有被拉伸变形
- [ ] 角色大小适合画面

## Jump

- [ ] 按跳跃键后切换到 Jump 动画
- [ ] 跳跃过程中角色方向正确
- [ ] 跳跃动画不会突然变大或变小
- [ ] 落地后能回到 Run 动画
- [ ] 落地没有卡住

## Throw

- [ ] 攻击时切换到 Throw 动画
- [ ] 投掷动作方向正确
- [ ] 投掷后能回到 Run 动画
- [ ] 卫生巾 projectile 能正常出现
- [ ] 攻击不会打断游戏逻辑

## Charge

- [ ] 长按空格能进入蓄力状态
- [ ] 蓄力动画正常显示
- [ ] 松开后能触发撞击动作
- [ ] 撞击后能回到 Run 动画
- [ ] Charge 不会让角色卡死

---

# 2. 碰撞与手感检查

## 玩家碰撞

- [ ] 主角视觉位置与碰撞框基本一致
- [ ] 没有“看起来没碰到但判定失败”
- [ ] 没有“明显碰到了但没判定”
- [ ] 跳跃能正常越过烟雾
- [ ] 攻击能正常命中可攻击障碍
- [ ] Charge 能正常撞飞目标

## 手感

- [ ] 跳跃响应及时
- [ ] 攻击响应及时
- [ ] Charge 响应清楚
- [ ] 操作不会有明显延迟
- [ ] 玩家在 10 秒内能理解基本操作

---

# 3. Fearless Mode 检查

## 触发

- [ ] 连续击飞三个障碍后能触发 Fearless Mode
- [ ] 触发逻辑没有被改坏
- [ ] 触发时有明显视觉提示
- [ ] 屏幕出现 FEARLESS 或类似提示

## 视觉

- [ ] 主角切换到 Fearless 视觉
- [ ] 红发更有动感
- [ ] 有发光 / 残影 / 速度线中的至少一种
- [ ] Fearless 状态和普通状态明显不同

## 结束

- [ ] Fearless 有倒计时或结束反馈
- [ ] 结束后能恢复普通状态
- [ ] 结束后游戏不崩溃
- [ ] 结束后主角动画正常

---

# 4. 三个障碍物检查

## Smoke

- [ ] 烟雾视觉清晰
- [ ] 玩家能一眼看出这是烟雾障碍
- [ ] 烟雾没有遮挡整个画面
- [ ] 跳过烟雾能得分
- [ ] 碰到烟雾有反馈

## Harasser

- [ ] 角色轮廓清楚
- [ ] 伸手动作明显
- [ ] 和 Drunk Man 区分明显
- [ ] 卫生巾命中后有反馈
- [ ] 被击中后能消失或飞出

## Drunk Man

- [ ] 醉酒摇晃感明显
- [ ] 不会和 Harasser 混淆
- [ ] Charge 撞飞反馈明显
- [ ] 撞飞时有漫画感
- [ ] 飞出屏幕不会残留碰撞体

---

# 5. 卫生巾道具检查

- [ ] 卫生巾图标清晰可识别
- [ ] 投掷时方向正确
- [ ] 飞行速度合理
- [ ] 不会太大或太小
- [ ] 命中障碍后消失
- [ ] 卫生巾数量 HUD 正常减少
- [ ] 拾取或补给逻辑没有被破坏
- [ ] 数量上限仍然正确

---

# 6. 背景检查

## 白天背景

- [ ] 白天背景能正常显示
- [ ] 有广州城市特征
- [ ] 广州塔 / 骑楼 / CBD / 城市道路至少出现一类明显元素
- [ ] 背景不会遮挡玩家
- [ ] 跑道区域清晰

## 黑夜背景

- [ ] 黑夜背景能正常显示
- [ ] 夜晚氛围明显
- [ ] 霓虹灯 / 城市灯光明显
- [ ] 不会太暗导致角色看不清
- [ ] 障碍物在夜景中仍然可读

## 昼夜切换

- [ ] 白天到黑夜能正常切换
- [ ] 切换时不闪屏或崩溃
- [ ] 切换后 UI 仍然可读
- [ ] 切换后碰撞逻辑不受影响

---

# 7. UI 检查

## HUD

- [ ] 生命值显示正常
- [ ] Score 显示正常
- [ ] Courage Bar 显示正常
- [ ] Fearless Timer 显示正常
- [ ] 卫生巾数量显示正常
- [ ] UI 没有遮挡主角和障碍
- [ ] UI 风格和像素画风一致

## Game Over

- [ ] 失败后不显示生硬的 Game Over
- [ ] 出现幽默文案
- [ ] 分数显示正确
- [ ] Restart 按钮醒目
- [ ] 点击 Restart 后能重新开始

---

# 8. Comic FX 与情绪反馈检查

## 攻击反馈

- [ ] 命中时有 BOOM / BANG / 爆炸 / 星星中的至少一种反馈
- [ ] 撞飞时有明显视觉冲击
- [ ] 有轻微屏幕震动或冲击感
- [ ] 特效不会遮挡太久

## 文案弹窗

- [ ] 跳跃成功后可能出现幽默对白
- [ ] 攻击成功后可能出现毒舌对白
- [ ] 撞飞后可能出现夸张对白
- [ ] 文案持续时间短，不影响操作
- [ ] 文案位置不遮挡主角太久

## Hype System

- [ ] 连续 5 次无伤后触发中央情绪奖励
- [ ] 文案包括类似：
  - 👑 姐妹杀疯了！
  - ⚡ 谁都拦不住！
  - 🚀 一路狂飙！
  - 🔥 今天状态超神！
- [ ] 中央文案出现时间短
- [ ] 有 Pop / 放大 / 震动等表现
- [ ] 不影响玩家继续操作

- [ ] 背景没有抢戏
- [ ] 特效没有遮挡核心操作区域

# 13. 最后一轮试玩流程

提交前请连续玩 3 局。

## 第一局

只测试基础操作：

- 跑
- 跳
- 攻击
- Charge
- 失败
- Restart

## 第二局

测试视觉反馈：

- Jump 文案
- Attack 文案
- BOOM
- 撞飞
- Hype
- Fearless

## 第三局

模拟真实玩家：

不要刻意测试。

只正常玩。

结束后问自己：

> 我会不会想点「再跑一局」？

如果答案是“会”，今晚 Demo 可以交。
