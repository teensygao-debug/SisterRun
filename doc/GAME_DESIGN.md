# GAME_DESIGN.md

# SISTER, RUN!（姐妹快跑）

Version 1.0

---

# Game Vision

《姐妹快跑》是一款 2D 横版无限跑酷网页游戏。

玩家扮演一位年轻女性，在广州城市街道不断向前奔跑。

游戏将现实生活中的烦心事，转化为轻松、夸张、充满漫画感的跑酷体验。

它不是一款强调受害感的游戏。

而是一款强调：

**自由、速度、反击、幽默、情绪释放** 的游戏。

玩家完成一局后，最重要的感受应该是：

> 「好爽，再来一局。」

---

# Core Design Pillars

整个游戏必须始终围绕以下四个核心设计原则。

## 1. Easy to Play

任何玩家都可以在 10 秒内学会。

操作永远保持简单。

不增加复杂按键。

不增加复杂系统。

---

## 2. Fun First

玩法永远优先于表达。

任何设计都必须首先保证：

好玩。

流畅。

有爽感。

如果一个设计虽然有意义，

但不好玩，

应该删除。

---

## 3. Emotional Release

游戏把现实生活中的烦心事，

转化成轻松、

幽默、

夸张、

具有漫画感的互动。

玩家获得的是：

情绪释放。

不是愤怒积累。

---

## 4. One More Run

玩家结束一局以后，

应该立刻想：

"再来一局。"

整个游戏必须围绕：

短局、

快节奏、

高反馈、

不断挑战自己。

---

# Core Gameplay Loop

Run

↓

Jump

↓

Attack

↓

Combo

↓

Fearless Mode

↓

Higher Score

↓

Play Again

这是整个游戏唯一需要不断强化的循环。

不要增加复杂循环。

---

# Player Actions

玩家只有三种核心操作。

Jump

跳跃。

躲避障碍。

Attack

点击攻击。

消耗卫生巾。

Charge

长按蓄力。

撞飞障碍。

除此之外，

不要增加新操作。

---

# Enemy Philosophy

障碍不是怪物。

障碍代表：

城市中的不当行为。

玩家是在突破障碍，

不是击败敌人。

Demo 阶段保留三个障碍：

Smoke

公共场所吸烟产生的烟雾。

Harasser

实施骚扰行为的人。

Drunk Man

醉酒挡路的人。

整个表现采用：

漫画、

幽默、

夸张。

禁止写实暴力。

---

# Fearless Mode

Fearless Mode

是整个 Demo 最重要的高潮体验。

触发后：

速度提升。

角色发光。

头发飞扬。

背景音乐更燃。

速度线增强。

镜头更有冲击力。

玩家应该立刻感觉：

"没人能拦住我。"

---

# Comic Feedback

游戏必须持续奖励玩家。

成功跳跃：

随机对白。

成功攻击：

随机吐槽。

连续 Combo：

中央漫画字幕。

Fearless：

全屏庆祝。

玩家在体验中会及时获得正反馈：

"干得漂亮。"

而不是：

"你失败了。"

# Demo Scope

Demo 时长：

约 3 分钟。

目标：

玩家玩完以后，

立即点击：

Restart。

不要制作：

剧情。

商城。

装备。

技能树。

任务。

排行榜。

成就系统。

这些暂时都不是 Demo 的目标。

---

# Success Metrics

如果试玩玩家出现以下行为，

说明 Demo 成功。

笑出来。

主动连续玩 3 局以上。

分享给朋友试玩。

说：

"好爽。"

"这个有意思。"

"我还想再玩。"

而不是：

"剧情不错。"

"数值很好。"

"系统很多。"

---

# Things We Will Never Build

为了保持游戏体验，

以下内容原则上不加入：

开放世界。

RPG 数值成长。

抽卡。

装备强化。

复杂技能树。

复杂剧情。

长教程。

繁琐 UI。

重复确认弹窗。

游戏必须始终保持：

简单。

快速。

直接。

爽。
