# Art Direction (Highest Priority)

This project has a strict visual style.

Do NOT redesign the art style.

All sprites, proportions, animation style and colors MUST follow the supplied reference sheet.

The attached image is the ONLY visual reference.

Requirements:

- True 8-bit pixel art
- Hand-crafted sprite style
- No AI painterly rendering
- No voxel
- No chibi
- No minimalist head-body characters
- Full-body pixel character with proper human proportions
- Similar animation quality to Celeste
- Similar silhouette to Lola Rennt (Run Lola Run)
- Clean pixel outlines
- Bright saturated colors
- Cyberpunk Guangzhou city background
- Every sprite should look like it belongs to the same sprite sheet.

Never invent another art style.
Never replace the character design.
Use the attached sprite sheet as the single source of truth.
