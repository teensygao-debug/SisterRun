# SisterRun Assets

This folder is reserved for Visual Freeze assets.

All assets must follow:

- `../doc/ART_BIBLE.md`
- `../doc/ART_REFACTOR.md`

## Hard Rules

- No random asset packs.
- No mixed artist styles.
- No placeholder art in final Visual Freeze assets.
- Character and obstacle sprites use 64 x 64 px transparent PNG frames unless a documented exception is approved.
- All sprites use a 1 px dark outline.
- All sprites use the same top-left 45 degree light source.
- Sprite feet share the same baseline.

## Directory Plan

- `sprites/player/`
- `sprites/obstacles/`
- `sprites/items/`
- `background/day/`
- `background/night/`
- `ui/`
- `fx/`
